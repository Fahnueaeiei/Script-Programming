# Week 11 — Enhanced Task Manager (Design Scaffold)

A modular CLI Task Manager following the Week 11 project planning and design exercise.

## Run

```bash
python3 main.py
```

No third-party dependencies required. Tasks are saved automatically to `data/tasks.json`.

## Modules
- `src/task.py`: Task, DueDateTask, PriorityTask with tags
- `src/data_persistence.py`: JSON serialization and persistence
- `src/task_manager.py`: task operations and planned advanced features
- `src/cli_interface.py`: command-line interaction
- `main.py`: entry point

Options 1–6 are functional. Options 7–9 are intentionally placeholders, consistent with the Week 11 **design scaffold** instructions. See [PLAN.md](PLAN.md).
